# iPhone 快捷指令

睡觉、起床、出去玩及自定义状态手动运行；吃饭、到办公室按地点自动运行。所有指令调用 **Presence · 上报**，设备令牌只配置一次。

新增出游功能：更新后端并重启，更新网页，然后只导入 **Presence · 出去玩** 和 **Presence · 结束出去玩**。继续使用已有“Presence · 上报”，无需替换或重填令牌。

运行“出去玩”时填写描述，例如“探索老城区”“街头摄影”“到处逛逛”（默认值），也可清空后继续。最多 120 字，去除首尾空白；取消输入不会上报。网页显示“出去玩 · 探索老城区”，留空时显示“出去玩”。不要在描述前再写“正在”或“出去玩”。回来后运行“结束出去玩”，只结束本次出游，重复结束无副作用。

出游最长 24 小时兜底，超过旧版的 3 小时仍会保留；再次运行“出去玩”会结束上一段并开始新记录。到办公室或睡觉也会结束出游；吃饭、上课暂时优先显示，出游仍继续记录并列为伴随状态。保留活动等级 2：科研/开发等级更高时，出游列为伴随状态。

开始时间、结束时间和描述长期保存到 SQLite 的 `manual_states` 与 `segments`，不随原始信号清理。今日时长归入“出去玩”，时间线保留描述；跨日按每天边界分摊。新出游记录在服务器停机期间连续计时，重启不会重复累计；停机时到期的也按到期时间结算。旧版“出门”记录保持原样。

刷手机直接复用“上报”，21 个 App 的 42 个原生自动化模板已命名并填好上报字典，触发器的 App 选择留空，见 [手机 App 安装说明与文案](PHONE.md)。需要同时更新共用上报和服务器规则。

## 1. 生成与导入

本机生成并签名：

```sh
cd /Users/ignat/Developer/Presence/server
uv run --locked python ../shortcuts/build.py --sign
```

签名后的文件在 `shortcuts/build/`。将这些文件通过 AirDrop 或 iCloud Drive 传到 iPhone，在“文件”中点开，添加到“快捷指令”。首次安装先导入 **Presence · 上报**，再导入其他 10 个；已有用户只添加需要的新指令。保留名称，其他指令按名称调用它。源文件在 `source/`，是可审查的 XML，未签名，不能直接当作 iPhone 安装包。

导入“上报”时，填写服务器 `settings.toml` 的 `[devices]` 下 `iphone` 对应的令牌，**只填令牌，不加 `Bearer`**。若没有出现导入提问，编辑该指令顶部的“文本”，替换 `__IPHONE_DEVICE_TOKEN__`。服务器端必须已配置同一个非空令牌；不要使用 Mac 的令牌。此仓库生成的文件均不含真实令牌。

接口固定为 `https://api.ignat.ai/presence/api/signal`。如服务器地址不同，编辑“上报”的 URL 动作即可。请求格式：

```json
{"kind":"manual","data":{"state":"office"}}
```

使用 POST 和 `Authorization: Bearer <iphone 令牌>`。为避免 iOS 导入时把整个 JSON 字典变量变成空的“0 项”，先用“文本”动作将原生字典序列化为 JSON，再将请求体设为“文件”，发送这段文本，头部设 `Content-Type: application/json`。省略 `ts`，以服务器收到请求的时间为准；无需上传坐标。`ttl` 是信号保活时间，状态的持续时间由 `minutes` 和后端规则控制。

首次在 iPhone 上手动运行一次每个状态指令，允许访问 `api.ignat.ai`，并允许调用“Presence · 上报”。这些真实运行会改变公开状态，建议依次测试“睡觉 → 起床 → 到办公室 → 吃饭 → 离开办公室”，最后再设置当前实际状态。自定义文字会公开显示。

## 2. 指令行为

| 指令 | 触发 | 行为 |
| --- | --- | --- |
| Presence · 睡觉 | 手动点按 | 开始睡觉，结束吃饭和办公室锚定；最长 14 小时 |
| Presence · 起床 | 手动点按 | 只结束睡觉 |
| Presence · 吃饭 | 到达食堂 | 吃饭 60 分钟；办公室锚定保留，到期后恢复 |
| Presence · 停止吃饭 | 手动点按 | 只结束吃饭，恢复办公室等已有状态；重复点按无副作用，不会结束睡觉 |
| Presence · 到办公室 | 到达办公室 | 开启“在办公室搞科研”锚定，结束出门；最长 12 小时 |
| Presence · 离开办公室 | 离开办公室 | 只结束办公室锚定 |
| Presence · 出去玩 | 手动点按 | 输入可选的公开描述，开始出游并结束办公室；最长 24 小时 |
| Presence · 结束出去玩 | 手动点按 | 结束出游并保存时长，保留其他状态 |
| Presence · 自定义状态 | 手动点按 | 输入文字、持续分钟数（1～1440，默认 120）和优先级（默认 2）；1 为锚定，2、3… 为对应活动等级 |
| Presence · 退出自定义状态 | 手动点按 | 只结束自定义锚定或活动，保留其他状态；重复运行无副作用 |

睡觉与起床不绑定专注模式或闹钟。后端已有的“Mac 连续活跃 10 分钟视为起床”兜底规则仍有效。

“科研锚定”表示在办公室时主状态保持“在办公室搞科研”，合盖、空闲不会结束。今日科研时长仍按 Mac 实际科研活动统计，不会把整段办公室时间都算成科研。上课优先于吃饭、睡觉，吃饭和睡觉优先于办公室。自定义优先级 1 为最高的手动锚定，优先显示但不结束这些已有状态；优先级 2、3… 属于活动，数字越小越靠前，仍由锚定状态优先显示。

更新自定义功能时，只需替换“自定义状态”并新增“退出自定义状态”，沿用已配置令牌的“上报”。服务器需要同步 `presence/engine.py`、`presence/main.py` 和 `config/rules.yaml` 并重启；旧后端不会将优先级 1 作为锚定，也不认识 `stop_custom`。自定义锚定到期或退出后，恢复显示仍有效的上课、吃饭、办公室或其他活动。锚定模式记在统计的 anchor 线上，普通等级记在 activity 线上；优先级随自定义状态持久保存。

## 3. iPhone 上配置地点自动化

地点属于个人自动化，需要在 iPhone 上创建，不能通过这些 `.shortcut` 文件一起导入。到达和离开均可设为自动运行，见 [Apple 自动化说明](https://support.apple.com/guide/shortcuts/enable-or-disable-a-personal-automation-apd602971e63/ios)。

**到达食堂 → 吃饭**：

1. 打开“快捷指令”→“自动化”→“+”→“到达”。
2. 位置选择实际食堂，调整地图上的范围，时间范围选“任何时间”。
3. 选择“立即运行”，点“下一步”。
4. 选择“Presence · 吃饭”；如果进入空白编辑器，添加“运行快捷指令”动作并选择它。
5. 保存。有多个常去食堂时，为每个地点各建一条。

吃饭自动到期；吃完可手动运行“Presence · 停止吃饭”。如希望离开食堂自动结束，也可新建“离开”该地点的自动化，运行“Presence · 停止吃饭”。一天内重新进入食堂会重新开始 60 分钟。

“停止吃饭”使用新的 `manual` 状态 `stop_eat`，需要将服务器更新到包含此功能的代码并重启（运行服务的终端按 Control+C，再执行 `scripts/start.sh`）。旧后端会忽略未知状态，即使返回 `accepted: 1` 也不会结束吃饭。已有用户只需替换“自定义状态”并新增“停止吃饭”，不必替换已配置令牌的“上报”。

**到达办公室 → 科研锚定**：

按相同步骤新建“到达”自动化，选择办公室位置、任何时间、立即运行，运行“Presence · 到办公室”。

**离开办公室 → 结束锚定**：

新建“离开”自动化，使用与到达办公室相同的位置与范围、任何时间、立即运行，运行“Presence · 离开办公室”。不要选择清除全部状态。

地理围栏有延迟，范围也可能覆盖附近建筑。食堂和办公室靠得近时，应尽量缩小重叠范围；办公室自动化只在跨越范围时触发，人在办公室超过 12 小时需手动再运行一次“到办公室”。后台自动化成功时静默，失败时查看自动化的系统错误；断网不会补发历史状态，恢复网络后重新运行对应指令。

## 4. 验收与排障

- 若旧版提示“未向设定字典值操作中的键 data 提供值”，这是旧版导出字段格式错误。重新生成并只替换“Presence · 上报”，再填写原来的 iphone 令牌即可；其他 6 个指令及地点自动化不需要重建。新版使用文本令牌绑定 `data` 的值，目标字典和请求 URL 使用各自动作的专属输入字段。
- 若旧版提示“服务器未返回 accepted”，展开“获取 URL 内容”检查 JSON 请求体是否显示“0 项”；这是旧版整字典变量导入丢失的问题。新版改用“文件”正文发送 JSON 文本，并在失败时显示服务器实际响应。
- 在手机手动运行“睡觉”，打开 `https://now.ignat.ai` 查看睡觉状态；课程期间会出现在伴随状态中。点“起床”后睡觉消失。
- 点“到办公室”，应出现“在办公室搞科研”；点“吃饭”后吃饭优先、办公室保留。点“离开办公室”只撤销办公室。
- 自定义输入引号、换行、中文等，网页应原样显示。使用原生字典生成 JSON，不拼接用户文字。
- 自定义文字读取修复：替换文本动作的输入使用文本令牌，去除前后空白后按字符数判空。只包含空格、换行的输入会拒绝；分钟数使用数字专属默认值 120。
- 实际经过食堂和办公室围栏，分别确认进入和离开自动化。桌面端签名及接口测试不能代替 iPhone 真机地点验收。
- 401：检查 `iphone` 令牌和服务器配置是否一致；修改服务器配置后重启服务器。
- 网络错误：检查服务器、Tunnel 和手机网络。第一次运行先在解锁状态下处理权限弹窗。
- 找不到“上报”：检查已导入且名称完全一致；如改了名称，编辑每个指令的“运行快捷指令”动作重新选择。
- 提示未接收：只在响应 `accepted = 1` 时视为成功；不会在失败时显示成功通知。
